# Eco-Critical: ห้องเรียนภูมิศาสตร์

ขอบเขตที่เจ้าของยืนยัน 6 พฤศจิกายน 2026: ห้องเรียนเดียวสำหรับ ม.ปลาย ใช้ frontend ต้นฉบับ Mentingo ใน React เดิม เพิ่มบัญชีและข้อมูลจริงบน Cloudflare Pages + D1 แทนบทบาทและข้อมูลเดโมในเบราว์เซอร์

## Workflow

1. สมัครชื่อผู้ใช้ รหัสผ่าน และชื่อที่แสดง อีเมลไม่บังคับ สิทธิ์เริ่มต้นเป็นนักเรียนและรออนุมัติเสมอ
2. ครู/แอดมินตรวจผู้สมัครก่อนอนุมัติ ผู้ที่ยังไม่อนุมัติอ่านบทเรียน เอกสาร หรือบอร์ดผ่าน API ไม่ได้
3. เรียนกรณีศึกษาฝุ่นและควันพิษ ทำกิจกรรมและแบบทดสอบ คะแนนคำนวณบนเซิร์ฟเวอร์ ความก้าวหน้าผูกกับบัญชีและข้ามเครื่องได้
4. ครูเพิ่ม/แก้เนื้อหาและแบบทดสอบ อัปโหลด TXT/Markdown โดยรอเซิร์ฟเวอร์ยืนยันก่อนปิดฟอร์ม ใช้ revision ป้องกันเขียนทับการแก้ของครูอีกคน
5. AI ค้นข้อความจากเอกสารและเนื้อหาบทเรียนที่ครูบันทึก แล้วเรียก Gemini ฝั่งเซิร์ฟเวอร์พร้อมแหล่งอ้างอิง ถ้าไม่มีหลักฐานจะปฏิเสธ ถ้าไม่มี key จะแจ้งให้แอดมินตั้งค่า
6. บอร์ดใช้บัญชีที่อนุมัติแล้ว เห็นกระทู้/คำตอบร่วมกัน เจ้าของลบข้อความตนเองได้ ครูและแอดมินดูแลข้อความได้
7. แอดมินมอบสิทธิ์ครู/แอดมิน ระงับบัญชี และออกรหัสชั่วคราว ผู้ใช้ต้องเปลี่ยนรหัสก่อนใช้งาน ระบบกันลดสิทธิ์/ระงับแอดมินที่กำลังใช้และแอดมินคนสุดท้าย

## ส่วนประกอบ

| ส่วน | การทำงาน |
|---|---|
| บัญชี | Cookie HttpOnly/Secure/SameSite, salted PBKDF2 + server pepper, logout/revoke, บังคับเปลี่ยนรหัสตั้งต้น/ชั่วคราว |
| ผู้เรียน | รายชื่อ วันที่สมัคร สถานะ การเข้าใช้ล่าสุด ความก้าวหน้า/คะแนนรายบท ตามสิทธิ์ครูและผู้ดูแล |
| ห้องเรียน | ภูมิศาสตร์ มัธยมศึกษาตอนปลาย: 6 กรณีศึกษา 5 ประเทศ 1948–2026 และ 4 บทเรียนพื้นฐาน |
| เนื้อหา | ตัวแก้ข้อความและแบบทดสอบ TXT/MD สูงสุด 1 MB ต่อไฟล์ เก็บข้อความร่วมกันใน D1 |
| AI | Key เข้ารหัสฝั่งเซิร์ฟเวอร์ หน้าตั้งค่า/ทดสอบจริงเฉพาะแอดมิน ค้นข้อความแบบ lexical ไม่อ้างว่าเป็น vector embeddings |
| สนทนา | กระทู้ คำตอบ บริบทกรณีศึกษา ตรวจสิทธิ์ ลิมิตคำขอ และข้อความธรรมดาที่ React escape |
| ความปลอดภัย | ตรวจสิทธิ์ทุก endpoint, Origin check, SQL แบบ bind, เซสชันหมดอายุ และ audit log การเปลี่ยนสิทธิ์/ข้อมูลสำคัญ |

## เริ่มใช้จริง

บัญชี `admin` ใช้ค่าตั้งต้นตามที่เจ้าของกำหนด พร้อมรหัสตั้งค่าครั้งแรกแยกจากรหัสผ่าน เพื่อกันผู้เปิดลิงก์ทั่วไปยึดบัญชี เจ้าของอ่านข้อมูลจาก `.classroom-local/admin-setup.txt` ซึ่งไม่ส่งขึ้น GitHub และต้องเปลี่ยนรหัสก่อนเข้าหน้าจัดการ

แอดมินตั้ง Gemini key ในหน้า “ตั้งค่า AI” แล้วกด “ทดสอบเรียก Gemini จริง” การมี endpoint และผ่าน unit tests ไม่ใช่หลักฐานว่า key จริง/ความถูกต้องของโมเดลผ่านการตรวจแล้ว

## ข้อจำกัด

- Cloudflare รับ TXT/Markdown; PDF/DOCX ผ่าน collector ของ backend เดิมเป็นคนละเส้นทาง ไม่ได้อ้างว่ารันบน Pages
- ยังไม่มี SMTP/การกู้รหัสผ่านอีเมลอัตโนมัติ รุ่นนี้ใช้แอดมินออกรหัสชั่วคราว
- Chrome/emulation ไม่แทนการทดสอบบน iOS/Android จริงหรือการรับรอง WCAG
- ต้องสำรอง APP_SECRET อย่างปลอดภัย การสร้างค่านี้ทับโดยไม่มีแผนย้ายข้อมูลทำให้รหัสผ่านและการถอดรหัส Gemini key เดิมใช้ไม่ได้
